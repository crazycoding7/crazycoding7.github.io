1. AI是什么

​ AI即人工智能，是一门让机器模拟人类感知、学习、思考和决策的技术统称。

​ 核心: 算法+数据，让机器自动学习规律，用来替代人工做生产和决策。

  • 狭义

​ 日常说的 AI：大模型、深度学习，能聊天、写代码、创作、分析内容。

  • 广义

​ 包含：机器学习、图像识别、语音识别、推荐算法、自动驾驶等所有智能技术。

2. 什么是大语言模型(LLM)?

简单来说，大语言模型（Large Language Model，简称 LLM） 就是一个通过海量文本数据训练出来的、能够理解和生成人类语言的巨型神经网络。

你可以把它理解为一个吸收了人类绝大部分书面知识，并学会了语言规律（语法、逻辑、语境）的“超级大脑”。核心原理：通过上下文，预测下一个 token 的概率，逐字生成内容。本身没有意识，只是学习人类文本、逻辑、语法的规律，做概率续写。

3. 大语言模型原理?

Transformer的核心是“自注意力机制”：让序列中的每个元素都能直接、并行地与所有其他元素动态交互，并利用“多头”和“位置编码”来捕捉不同层面的关系和顺序，从而彻底解决了串行计算和长距离遗忘的难题。

核心点：

  1. 自注意力机制：所有内容全局互相关联，解决长文本、指代、远距离依赖。
  2. 多头注意力 + 全连接网络：多维度理解语义，支持深层堆叠、大规模并行训练。

用 Q (查询)、K (关键词)、V (内容) 计算文本之间相似度，

给相关内容加高权重、无关内容降权，从而抓住重点、理解上下文。

4. 为什么 2010 年有机器学习，没爆发？

  1. 算力：早年只有 CPU，无法训练深层大模型；
  2. 数据：没有移动互联网，海量文本数据不足；
  3. 算法：没有 Transformer，RNN 串行、易遗忘、不能并行；
  4. 模型：都是浅层机器学习，复杂逻辑理解不了。

5. 大模型怎么看懂问题、生成答案？

  1. 文本分词，转为向量数字；
  2. 注意力机制分析上下文、语义关系；
  3. 多层 Transformer 计算，输出下一个 Token 概率；
  4. 选择高概率内容逐字输出，循环生成整段回答。

6. 为什么回答通顺、有逻辑、有深度？

  1. 训练数据覆盖全网书籍、文档、专业知识；
  2. 学会人类固定语法、句式、因果逻辑；
  3. 深度来自：专业词汇 + 成熟行文模板 + 海量高质量内容模仿；
  4. 本质是模仿拟合，不是真正思考。

7. 什么是 AI 幻觉？

模型会一本正经编造错误事实、参数、资料。

原因：只有概率规律、没有真实认知，为了语句通顺，强行拼接错误内容。

8. RNN/LSTM 为什么被淘汰？

串行逐字计算，无法并行、训练慢；

长文本容易梯度消失，远距离信息遗忘严重。

9. 训练 vs 推理

  • 训练：用海量数据更新模型所有参数，吃算力、成本极高；
  • 推理：使用现成模型，用户提问实时生成回答，日常使用都是推理。

10. Token 是什么？

大模型最小计算单位，单个字、词语、符号、字母都算；

上下文限制、计费、长度统计全部按 Token 计算。

11. 企业三种落地方案

  1. Prompt：纯提示词约束，不改模型，成本最低；
  2. RAG：检索外部知识库，解决知识滞后、减少幻觉；
  3. 微调：用私有数据训练模型，适配专属业务。

12. 模型优化名词

  • 量化：降低参数精度，缩小体积、提速、低成本部署；
  • 蒸馏：大模型教小模型，压缩规模，保留核心能力。

13. 大模型三大短板

易幻觉、知识有时间截止、复杂强逻辑推理弱、无真实理解能力。

14. 国内大模型梯队

  • 强代码 / 推理：DeepSeek、通义千问、豆包
  • 通用文案：文心一言、腾讯混元、讯飞星火

15. LLM VS AI Agent

​ LLM只会说，不会做，你问一句它答一句；

​ AIAgent会说和会做，可以主动调用工具，有规划有步骤的处理问题。

一个完整的AI Agent = 大脑 + 计划 + 工具 + 记忆

  1. 大脑（LLM）
    就是大语言模型本身，负责”思考”和”决策”。
  • 理解你的目标
  • 拆解任务
  • 决定下一步做什么
  1. 规划能力（Planning）
    能把一个大目标拆成一步步的小任务。
  • 例子：你说”帮我订一张明天去上海的机票”
  • Agent会自己规划：
    1. 先查明天有哪些航班
    2. 对比价格和时间
    3. 选一个合适的
    4. 填写乘客信息
    5. 支付
  1. 工具使用（Tool Use）
    能调用外部工具来完成具体操作。
  • 常用工具：
    • 浏览器搜索（查信息）
    • 计算器（算数）
    • 代码解释器（写代码并运行）
    • API接口（查天气、订票、发邮件）
    • 数据库查询（找数据）
  1. 记忆（Memory）
    能记住之前说过什么、做过什么。
  • 短期记忆：记住当前对话的内容（比如你刚才说想要靠窗的座位）
  • 长期记忆：记住你的偏好（比如你每次订经济舱、不吃飞机餐）

16. Skills VS System Prompt

Skills 是大模型的外部能力扩展，通过工具或插件赋予模型搜索、计算、代码执行、API 调用等实际执行能力，用于增强模型解决真实问题的能力。

System Prompt 是系统级提示词，用于设定模型角色、行为规范、输出风格与约束条件，引导模型按照指定方式生成内容，不新增能力，只规范输出。
